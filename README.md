### 第 1 章　线性代数中的线性方程

| 节 | 核心内容 | 关键结论 / 定理 |
|:---:|---|---|
| 1.1 | 线性方程组、系数矩阵与增广矩阵、初等行变换（倍加 / 对换 / 倍乘） | 行变换后的方程组与原方程组等价；两个基本问题：**存在性**与**唯一性** |
| 1.2 | 阶梯形（REF）与简化阶梯形（RREF）、主元、向前 / 向后两阶段算法、基本变量与自由变量、欠定与超定系统、计算量 flops | RREF 唯一；定理 2：相容 ⟺ 最右列非主元列；解唯一 ⟺ 无自由变量 |
| 1.3 | 向量（八条代数性质）、线性组合、张成 Span、向量方程 | **b** ∈ Span{**a**₁, …, **a**ₙ} ⟺ 对应方程组相容；Span 几何：过原点的直线 / 平面 |
| 1.4 | 矩阵方程 **Ax** = **b**（**Ax** 即列向量的线性组合）及其计算 | 定理 3：线性方程组 ⇔ 向量方程 ⇔ 矩阵方程 ⇔ 增广矩阵；定理 4：每个 **b** 都有解 ⟺ 列张成 ℝᵐ（每行有主元）；定理 5：A(**u**+**v**) = A**u** + A**v**，A(c**u**) = c(A**u**) |
| 1.5 | 齐次方程组、平凡解 / 非平凡解、参数向量形式、解集几何 | 非平凡解 ⟺ 有自由变量；定理 6：非齐次解集 = 特解 **p** + 齐次解集（平移） |
| 1.6 | 应用：经济学均衡价格、化学方程式配平、网络流量 | 套路：实际问题 → **Ax** = **b** → 求解 → 回到实际解释 |
| 1.7 | 线性无关 / 线性相关的定义与矩阵判定 | 定理 7：相关 ⟺ 某向量是其余向量的线性组合；定理 8：p > n 必相关；定理 9：含零向量必相关 |
| 1.8 | 变换 / 映射 T：ℝⁿ → ℝᵐ（定义域、值域、像集）、线性变换（保加法 + 保数乘） | T 线性 ⟹ T(**0**) = **0**；矩阵变换都是线性变换；叠加原理 |
| 1.9 | 标准矩阵 A = [T(**e**₁) ⋯ T(**e**ₙ)]、几何变换（伸缩 / 剪切 / 反射 / 旋转 / 投影） | 定理 10：标准矩阵存在且唯一；定理 11：满射 ⟺ 列张成（每行有主元）；定理 12：单射 ⟺ 列线性无关（每列有主元）；onto 是存在性、one-to-one 是唯一性 |
| 1.10 | 电路网络（基尔霍夫电压定律 + 网孔电流法）、线性差分方程 **x**ₖ₊₁ = A**x**ₖ、转移矩阵 | Σ Rₖiₖ = Σ V源；**x**ₖ = Aᵏ**x**₀；转移矩阵各列非负且列和为 1 |

### 第 2 章　矩阵代数

| 节 | 核心内容 | 关键结论 / 定理 |
|:---:|---|---|
| 2.1 | 矩阵加法 / 数乘 / 乘法（行乘列、列视角、行视角三种算法）、矩阵的幂、转置 | 定理 1–3：分配律与结合律、c(AB) = (cA)B = A(cB)、(AB)ᵀ = BᵀAᵀ（**反序**）；注意：一般 AB ≠ BA，且无消去律（AB = AC ⇏ B = C） |
| 2.2 | 逆矩阵、2×2 求逆公式与行列式、初等矩阵、Gauss–Jordan 求逆法 | 定理 4–7：(AB)⁻¹ = B⁻¹A⁻¹（反序）、(Aᵀ)⁻¹ = (A⁻¹)ᵀ；A 可逆 ⟺ A 行等价于 I ⟺ A 是初等矩阵之积；[A I] 行化简 → [I A⁻¹] |
| 2.3 | 可逆矩阵定理、可逆线性变换、条件数与病态矩阵 | 12 条命题等价：可逆 ⟺ n 个主元 ⟺ Ax = 0 只有平凡解 ⟺ 列线性无关且张成 ℝⁿ ⟺ Aᵀ 可逆…；cond(A) ≈ 10ᵏ 预示损失约 k 位有效数字 |
| 2.4 | 分块矩阵加 / 乘、分块转置与分块对角、2×2 分块方程 | 定理 10（列-行展开）：AB = Σᵢ colᵢ(A)·rowᵢ(B)（外积之和）；分块逆引出 Schur 补 A₂₂ − A₂₁A₁₁⁻¹A₁₂ |
| 2.5 | LU 分解（倍加消元 + 倍数填入 L）、带状与三对角矩阵、电路梯形网络 | 先分解（≈n³/3）后求解（每方程组 2n²），远快于反复消元或先求逆；带状结构在 L、U 中保持；级联传输矩阵按信号**反序**相乘 |
| 2.6 | 列昂惕夫投入产出模型（消耗矩阵 C、最终需求 **d**） | x = Cx + d ⟺ (I − C)x = d；定理 11：C、d 非负且 C 各列和 < 1 ⟹ (I − C)⁻¹ 存在且非负 |
| 2.7 | 齐次坐标（2D 用 3×3、3D 用 4×4）、仿射变换、绕轴旋转、透视投影 | 平移纳入矩阵语言；复合 = 连乘（右边的先作用）；透视投影 (x, y, z) ↦ (x/(1 − z/d), y/(1 − z/d), 0)，近大远小 |
| 2.8 | ℝⁿ 的子空间、列空间 Col A 与零空间 Nul A、基的概念 | 定理 12：Nul A ⊆ ℝⁿ、Col A ⊆ ℝᵐ 都是子空间；Ax = **b** 相容 ⟺ **b** ∈ Col A；定理 13：A 的**主元列**构成 Col A 的基（Nul A 的基取自参数向量形式） |
| 2.9 | 坐标向量 [x]ʙ、维数、秩 rank A、基定理 | 定理 14（秩定理）：rank A + dim Nul A = n；定理 15（基定理）：p 维子空间中任意 p 个无关向量即为一组基，任意 p 个张成向量亦然 |

### 第 3 章　行列式

| 节 | 核心内容 | 关键结论 / 定理 |
|:---:|---|---|
| 3.1 | 余子式 Mᵢⱼ 与代数余子式 Cᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ、代数余因子展开求 det | 定理 1：可沿**任一行或列**展开；定理 2：三角矩阵 det = 对角元之积；计算策略选 **0 最多的行 / 列**展开 |
| 3.2 | 行列式的性质：三类初等行（列）变换的作用、行化简求 det、可逆性判据、乘法性质、对单个列的线性性质 | 定理 3：行交换变号 / 倍乘乘 k / 倍加不变；det A = (−1)ʳ × 主元之积；定理 4：A 可逆 ⟺ det A ≠ 0；定理 5：det Aᵀ = det A（⇒ 对列同样成立）；定理 6：det AB = (det A)(det B)，推论 det A⁻¹ = 1/det A、det(rA) = rⁿ det A；固定其余列时 T(**x**) = det[⋯ **x** ⋯] 是 ℝⁿ → ℝ 的**线性变换**（T(c**x**) = cT(**x**)、T(**u**+**v**) = T(**u**) + T(**v**)，对每个列分别线性），但 det(A+B) ≠ det A + det B |
| 3.3 | 克拉默法则、伴随矩阵 adj A 与逆矩阵公式、行列式的几何意义（面积 / 体积） | 定理 7（Cramer）：xᵢ = det Aᵢ(**b**) / det A；定理 8：A⁻¹ = (1/det A)·adj A；定理 9：\|det\| = 列张成的平行四边形面积（2×2）/ 平行六面体体积（3×3）；定理 10：线性变换按 \|det A\| 缩放一切面积 / 体积 |

### 第 4 章　向量空间

| 节 | 核心内容 | 关键结论 / 定理 |
|:---:|---|---|
| 4.1 | 向量空间定义（加法与数乘满足 10 条公理）、子空间三判定（零向量 ∈ H、加法 / 数乘封闭）、张成集、标准例子（ℝⁿ、信号空间 S、ℙₙ、Mₘₓₙ、函数空间） | 定理 1：Span{**v**₁, …, **v**ₚ} 是 V 的子空间；ℝ³ 的子空间只有 {**0**}、过原点直线、过原点平面与 ℝ³ 本身；判定子空间先看零向量是否属于 H，或把 H 写成 Span{⋯} |
| 4.2 | 零空间 Nul A ⊆ ℝⁿ（隐式：Ax = **0** 的全体解）、列空间 Col A ⊆ ℝᵐ（显式：列的张成）、行空间 Row A = Col Aᵀ、线性变换 T: V → W 的核 ker T 与值域 range(T) | 定理 2 / 3：Nul A、Col A 都是子空间；**b** ∈ Col A ⟺ Ax = **b** 相容；Nul A 的显式描述 = 参数向量形式（张成向量个数 = 自由变量个数）；ker T = {**0**} ⟺ T 单射；T(**x**) = A**x** 时 ker T = Nul A、range(T) = Col A；滑动平均 M₂ 的核由交替信号张成 |
| 4.3 | 线性无关 / 相关（c₁**v**₁ + ⋯ + cₚ**v**ₚ = **0** 是否只有零解）、基 = 无关 + 张成、Nul A / Col A / Row A 求基的标准方法、基是最小张成集也是最大无关集 | 定理 4（相关判据）：相关 ⟺ 某 **v**ⱼ 是它前面各向量的线性组合（含零向量必相关）；定理 5（张成集定理）：冗余向量可删去；定理 6：Col A 的基 = A 的**主元列**（取 A 本身的列）；定理 7：行等价 ⟹ 行空间相同，阶梯形的非零行构成 Row A 的基 |
| 4.4 | B-坐标 [x]ʙ 与坐标映射 **x** ↦ [x]ʙ、ℝⁿ 中的坐标变换矩阵 **x** = Pʙ[x]ʙ、ℙₙ 取标准基 {1, t, …, tⁿ} 时坐标向量 = 系数向量 | 定理 8（唯一表示）：每个 **x** ∈ V 写成基向量的线性组合的方式唯一；定理 9：坐标映射是 V → ℝⁿ 的线性同构（V ≅ ℝⁿ），保线性组合，无关 / 张成等性质在坐标映射下保持；坐标映射把抽象空间的计算搬到 ℝⁿ 中用矩阵完成 |
| 4.5 | 有限维 / 无限维（dim ℙₙ = n + 1，ℙ 与 S 无限维）、秩 rank A = dim Col A = 主元列数、零度 nullity A = dim Nul A、可逆矩阵定理续篇（m–q 条） | 定理 10 / 11：有含 n 个向量的基 ⟹ 多于 n 个向量必相关、每个基都恰含 n 个向量；定理 12：无关组可扩充成基，dim H ≤ dim V；定理 13（基定理）：p 维空间中 p 个无关向量（或 p 个张成向量）自动是基；定理 14（秩定理）：rank A + dim Nul A = n；Numerical Note：浮点下数主元求秩不可靠，实用中以 SVD 确定有效秩 |
| 4.6 | 两组基 B、C 下坐标的换算、ℝⁿ 中按基向量排成的矩阵 Pʙ 与 Pᴄ 计算、增广矩阵 [C \| B] 行化简为 [I \| P(C←B)] 一步求得、多组基的复合 | 定理 15：C-坐标 = P(C←B) × B-坐标，P(C←B) 的列恰为各 **b**ⱼ 的 C-坐标，可逆且 P(B←C) = P(C←B)⁻¹；ℝⁿ 中 P(C←B) = Pᴄ⁻¹Pʙ；复合 P(D←B) = P(D←C)·P(C←B) |
| 4.7 | 信号空间 S 与常用信号（单位冲激 δ、单位阶跃 υ、交替信号 α）、移位变换 S 与 S⁻¹、滑动平均 Mₘ、线性时不变（LTI）变换、有限长信号空间 Sₙ、有限支撑信号空间 | 定理 16：LTI ⟹ 线性；定理 17：Sₙ 是 n + 1 维的，基 {δ, Sδ, S²δ, …, Sⁿδ}，信号对应 (y₀, …, yₙ) ∈ ℝⁿ⁺¹；定理 18：{Sʲ(δ) : j ∈ ℤ} 是无限维有限支撑信号空间的基（每个信号是有限个脉冲的唯一组合） |
| 4.8 | 信号的线性无关与 Casorati 矩阵 C(k)、n 阶线性差分方程（齐次 / 非齐次）、辅助方程法、化为一阶方程组 **x**ₖ₊₁ = A**x**ₖ | Casorati 在某个 k 处可逆 ⟹ 信号无关（单向判别：处处奇异推不出相关）；定理 19：aₙ ≠ 0 时初值问题唯一可解（递推可向前亦可向后）；定理 20：n 阶齐次方程的解空间是 n 维的，辅助方程互异根给出无关解 {r₁ᵏ}, …, {rₙᵏ}（基本解集）；非齐次通解 = 特解 + 齐次通解 |
